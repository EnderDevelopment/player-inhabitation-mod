# Player Inhabitation Mod

Inhabit players and stop time in Minecraft

## Features

- Inhabit other players to control their actions
- Stop time to create strategic advantages

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/player-inhabitation-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

### Inhabiting Players

1. Obtain the Inhabitation Item
2. Right-click the player you want to inhabit
3. Control the inhabited player's actions

### Stopping Time

1. Place the Time Stop Block
2. Activate the block to stop time
3. Use the time stop to create strategic advantages

## Configuration

The mod does not have a configuration file. All settings are hardcoded.
